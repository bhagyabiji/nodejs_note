node_modules
------------
- modules are files/ js libraries that can be used in node.js based application

    - imports -> require
        syntax
        ------
          In frontend => import variable_name from 'module'

          In Backend =>
          const variable_name = require('module')


    - exports -> module.exports
        syntax
        ------
          In frontend => export default name

          In Backend =>
          module.exports = name 


  
- two types of modules
    1) built-in modules - already defined modules
    2) custom modules

  built-in modules
  ----------------
  1) file system modules 
        - Allows you to works with the files in your system.

        common use 
        ----------
        1) to read a file - readfile()
        2) to create a file - open()
        3) to update/write a file - write()
        4) to delete a file - unlink()
        5) to rename a file - rename()
    
    2) http module 
        - used to create a server which can handle http request
        - to create a server - createServer()
                    http.createServer((req , res)=> { }) 
                    req , res => request and response
        - to accept the request - listen()
    
    3) https module
        - used to create a server whoch can handle https request
        - to create a server - createServer()
    
    4) event modules 
        - to generate events
        - it is done with the help of eventEmitter class
        - created using on() method in the above class
        - execute - emit() method in the above class

Middleware : its a function which have the ability to break the request response cycle
- basically it have 3 arg -> req , res, next

    syntax
    ------
    const middleware = (req, res, next)=> {
    next() - to send the request to controller - logic part of the server side 
    }
    module.exports = middleware

- there are 2 types of Middleware
    1) Application specific middleware 
        - all the request in the application must pass through this middleware

        example:- 
            // import this in index.js file and use applicationMiddleware serverName.use(applicationMiddleware)

            const applicationMiddleware = (req, res , next)=> {
                //logic
                console.log('inside application specific middleware)
                next()
            }
            module.exports = applicationMiddleware

    2) Router specific middleware
        - middleware will be active only in a specific path 
    

we are using the router specific middleware to acces the token in a particular field, where we arent need of token verification all over, so using the router specific middleware

application specific - import in index.js , middleware is used by the server
router specific - import in router.js, place the middleware in the path where you want to use the middleware

MULTER
-------

- Multer is a node.js middleware for handling multipart/form-data, which is primarily used for uploading files.
    - Multer will not process any form which is not multipart (multipart/form-data).
    - Multer adds a body object and a file or files object to the request object.
    - The body object contains the values of the text fields of the form, the file or files object contains the files uploaded via the form.

    only one upload file - use -> upload.single('key')
    if it is an array of more than one file -> upload.array('key', max limit)
    if it is a object -> upload.fields('key', max limit)

    DiskStorage
    -----------
    - it is used to store the uploaded files 
    - is an object with 2 keys as destination and filename
    - destionation -> will have a function with 3 args-> req, file, callback (callback - )

    fileFilter
    ---------
    - function to control which files should be uploaded and which should be skipped.
    - function with 3 args- req, file, callback 
    - To reject this file pass `false`, like so:
        cb(null, false)
        
        To accept the file pass `true`, like so:
        cb(null, true)
        
        You can always pass an error if something goes wrong:
        cb(new Error('I don\'t have a clue!'))
    - type in backend - mimetype
    - name in backend - originalname - name of the file on users computer

loadStripe
-----------
This function returns a Promise that resolves with a newly created Stripe object once Stripe.js has loaded. It takes the same parameters passed when directly initializing a Stripe instance. If necessary, it will load Stripe.js for you by inserting the Stripe.js script tag. If you call loadStripe in a server environment it will resolve to null.
